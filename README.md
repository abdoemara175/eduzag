# منصة التعلم الجامعي الذكية - تطبيق الهاتف المحمول
## جامعة الزقازيق | كلية التربية النوعية

تطبيق هاتف محمول متكامل (Mobile-First MVP) مصمم خصيصاً لطلاب وأعضاء هيئة التدريس بكلية التربية النوعية - جامعة الزقازيق.
يستهدف التطبيق أبعاد شاشات الهواتف الذكية **390 × 844 px (iPhone 14 Viewport)**، مع واجهة كاملة باللغة العربية ونظام اتجاه اليمين إلى اليسار (RTL). يعمل التطبيق كواجهة أمامية ثابتة (Static Frontend) دون الحاجة لخادم خلفي، مع حفظ البيانات التفاعلية محلياً عبر `localStorage` لضمان إمكانية نشره بسهولة وسرعة على **GitHub Pages**.

## مميزات المشروع وتجربة المستخدم

### 1. تجربة الطالب (Student Workflow):
- **الرئيسية (Home):** ترحيب شخصي، بطاقة المحاضرة القادمة مع مؤقت وزر تسجيل الحضور، جدول اليوم، إحصائيات الحضور والتكليفات، إعلانات الكلية وتنبيهات الاختبارات المتاحة.
- **الجدول الدراسي (Schedule):** جدول أسبوعي كامل من السبت إلى الخميس، بطاقات المحاضرات (المقرر، الدكتور، القاعة، التوقيت، ونوع المحاضرة نظري/عملي)، مع ميزة **"استكشاف الشعب"** للتبديل بين شعبة (أ) وشعبة (ب).
- **المقررات (Courses):** المقررات المعتمدة (تصميم البرمجيات التعليمية، تطبيقات الذكاء الاصطناعي، الوسائط المتعددة، علم النفس التربوي، صيانة المعامل)، نسب الحضور لكل مقرر، بطاقة تفاصيل المقرر، الخطة الدراسية (Syllabus)، وروابط تحميل المراجع والشرائح.
- **التكليفات والواجبات (Assignments):** تصنيف التكليفات (الكل، مطلوب، تم التسليم، متأخر)، شاشة تفاصيل التكليف، وميزة **"تسليم التكليف"** التفاعلية برفع ملف وملاحظات وتحديث الحالة فوراً.
- **الاختبارات (Quizzes & Exams):** الامتحانات القادمة والنشطة والسابقة، بطاقة التعليمات وقواعد النزاهة، وزر بدء الامتحان.
- **شاشة الاختبار المركزية (Exam Mode):** واجهة مخصصة تركز على الأسئلة، مؤقت عد تنازلي، شريط تقدم، شبكة تنقل بين الأسئلة، أسئلة اختيار من متعدد وصح/خطأ، رسالة تأكيد قبل التسليم، وشاشة إعلان النتيجة والدرجة المستحقة.
- **محاكاة فحص نزاهة الاختبار (Exam Integrity Simulation):** رصد خروج الطالب عن شاشة الاختبار أو تبديل النوافذ أو فقد التركيز، وإظهار تنبيه فوري: *"تم رصد مغادرة شاشة الاختبار. يرجى العودة إلى الاختبار"* مع عداد تراكمي للتنبيهات، وتسجيل النشاط تلقائياً في تقرير الأستاذ.
- **الحضور الذكي (QR Code Attendance):** نسبة الحضور العامة والمفصلة، وشاشة محاكاة مسح رمز QR بقاعات الكلية مع تأكيد الحضور الفوري.
- **مركز الإشعارات (Notifications):** تنبيهات مصنفة (أكاديمية، اختبارات، تكليفات، نزاهة) مع تمييز المقروء وغير المقروء.
- **الملف الشخصي (Profile):** بيانات الطالب الرسمية (الجامعة، الكلية، القسم، الفرقة، الشعبة، كود الطالب، المرشد الأكاديمي، والمعدل التراكمي GPA)، إعدادات التنبيهات، وخيار تسجيل الخروج أو التبديل للدكتور.

### 2. تجربة عضو هيئة التدريس (Doctor / Faculty Member):
- **لوحة التحكم (Doctor Dashboard):** المقررات المكلف بها، إجمالي الطلاب المسجلين، قائمة التكليفات التي تنتظر التصحيح، تنبيهات جلسات الاختبارات، وإجراءات سريعة.
- **المقررات (Doctor Courses):** استعراض المقررات وجداول قاعاتها وعدد الطلاب والتكليفات والاختبارات المرتبطة بكل مقرر.
- **نشر تكليف جديد (Create Assignment):** نموذج متكامل لتحديد عنوان التكليف، المقرر، الوصف والمعايير، وتاريخ التسليم، والدرجة؛ بمجرد نشره ينعكس فوراً لدى الطلاب.
- **إنشاء اختبار إلكتروني (Create Exam):** معالج من خطوتين لإدخال بيانات الامتحان وتاريخه ومدته، ثم بناء الأسئلة (اختيار من متعدد / صح أو خطأ) وتحديد الإجابات الصحيحة وتوزيع الدرجات ونشره للطلاب مباشرة.
- **قائمة الطلاب (Students Roster):** سجل كامل لطلاب الفرقة مع إمكانية البحث بالاسم أو الكود، وفلترة الشعب، ومتابعة نسب الحضور ومتوسط الدرجات والتكليفات.
- **تقرير نزاهة الاختبار (Exam Integrity Report):** متابعة الأنشطة غير الاعتيادية أثناء جلسات الاختبارات بصياغة مهنية وأكاديمية هادئة (*"نشاط مشبوه"*، *"يحتاج إلى مراجعة"* مثل مغادرة الشاشة أو انقطاع الاتصال)، مع أزرار لاعتماد النتيجة أو طلب مراجعة شفهية.

1. افتح موجه الأوامر في مجلد المشروع:

2. قم بتثبيت الحزم (في حال لم تكن مثبتة):

## النشر على GitHub Pages (Deploy to GitHub Pages)

المشروع مُهيأ مسبقاً برابط نسبي `base: './'` في `vite.config.ts`، مما يتيح نشره دون أية تعديلات:

### الطريقة الأولى (عبر فرع gh-pages):
1. قم بتهيئة مستودع Git وربطه بحسابك على GitHub:
```bash
git init
git add .
git commit -m "feat: Zagazig University Mobile App MVP"
git remote add origin https://github.com/<your-username>/<repo-name>.git
git push -u origin main
```
2. ابنِ المشروع:
```bash
npm run build
```
3. ادفع محتويات مجلد `dist/` إلى فرع `gh-pages`:
```bash
git subtree push --prefix dist origin gh-pages
```

### الطريقة الثانية (عبر GitHub Actions التلقائي):
يمكنك إضافة ملف سير عمل `.github/workflows/deploy.yml` لنشر المجلد `dist` تلقائياً عند أي Push على فرع `main`.
